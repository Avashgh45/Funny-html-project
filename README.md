# A few words about this project
**Hello, this proect is an funny project with html and Python. with, pythin you will create a local webserver that is accessibale on your LAN. **
# How To use it
**Clone the repo. In Linux(YOU NEED TO HAVE PYTHON INSTALLED, you have to open the terminal in the created directory and type "sudo chmod +x webserver.py" and then in your terminal, type "python webserver.py" and after that you just need to open your Browser and type "127.0.0.1' (or your computer's private ip) and BOOM! you had done it. you can enjoy the power of html :)**
**and for Windows users(YOU NEED TO HAVE PYTHON INSTALLED), you should clone the repo,or jus download the zip in github, unzip it, then you should open cmd in the created folder, then you should type "python webserver.py" and then, open your browser and type "127.0.0.1 (or your computer's private ip) and BOOM! you had done it. ypu can also enjoy the power of html**
